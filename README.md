# عَ الماشي — Digital Menu ☕️

> A digital menu interface for the **عَ الماشي** takeaway drinks and snacks brand.

**Stack:** React · Vite · JavaScript · CSS

## About
This repository contains the frontend for a menu-oriented web experience. Content is organized separately from reusable React UI components, making it easier to present products and maintain the interface.

## Repository structure
| Path | Purpose |
| --- | --- |
| `src/App.jsx` | Main React application |
| `src/components/` | UI components |
| `src/data/` | Menu/application data |
| `src/App.css` and `src/index.css` | Visual styles |
| `public/` | Public assets |

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Engineering focus
A lightweight, maintainable frontend with component reuse and structured menu content. For a live deployment, verify that product names, prices, availability and ordering details are current.
